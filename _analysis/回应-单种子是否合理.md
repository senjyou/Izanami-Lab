# 回应质疑：单种子真的合理吗？

> 你的质疑：在模拟器中见过 100 样本的模拟，**上下限超过两倍**的阵容。这种用 1 个种子无法体现真实水平。
> **你的质疑是对的方向，但结论需要修正——而且我找到了 2 倍上下限的真正来源。**

---

## 0. 结论先说

| 问题 | 答案 |
| --- | --- |
| 100 样本上下限超过 2 倍，可能吗？ | **在「复合战术演习」里可能；在「战术演习」里数学上不可能** |
| 我之前的 1 种子结论错了吗？ | **对战术演习成立，对复合战术演习不成立** |
| 单种子到底合不合理？ | **取决于模式**——这比我原来的说法更精确 |

**我找到了 2 倍的来源：不是战术演习，是「复合战术演习」。** 它报告 `最高分数/最低分数`，而战术演习的 `_compute_score_statistics` 也报告——**两者是不同模式，变异性差一个量级**。

**在战术演习模式下，2 倍的上下限需要 4 倍的波动率——不是"样本不够"，是分布本身不允许。**

## 2. 那 2 倍到底从哪来？——找到源头了

我扫了所有 GUI 标签页，报告 `最高分/最低分` 的只有两个：

| 标签页 | 模式 | 得分定义 |
| --- | --- | --- |
| 战术演习 | `TacticalExerciseController` | 单场 5 回合，对敌伤害−敌方回复 |
| **复合战术演习** | `CompositeTacticController` | **多支队伍依次作战，Σ 各队对 BOSS 伤害** |

`composite_tactic_controller.py:160`：

```python
for team_index in range(len(self._teams)):     # 逐队战斗
    team_result = self._run_team_battle(team_index)
    ...
total_score = sum(r["damage_to_boss"] for r in self._team_results)   # :192
```

**这就是关键差异**：

| | 战术演习 | 复合战术演习 |
| --- | --- | --- |
| 战斗场数 | 1 场 | **N 支队 × 每队多回合** |
| 波动来源 | 单场暴击/目标选择 | **每队独立掷骰 + 团灭判定 + BOSS 阶段推进** |
| 是否有"团灭" | 固定 5 回合 | **有 `team_wiped`，一队崩了后续全变** |
| 结构性断点 | 无 | **BOSS 跨阶段、被击杀次数**（`:196-197`） |

**复合模式下，一队提前团灭或 BOSS 阶段推进，会让总分产生结构性跳变**——不是同一分布的随机波动，而是**不同"分支结果"之间的差异**。这完全能产生 2 倍以上的上下限。

**所以你在模拟器里看到 2 倍，几乎肯定是复合战术演习（或含团灭判定的模式），不是战术演习。**

## 3. 这对"单种子"结论意味着什么

### 我原来的说法需要收窄

我之前说"1–2 种子粗筛已足够"——**那个结论的适用范围是战术演习**，依据是：

- 分布近似正态（偏度 0.51、峰度 0.08）
- 实测 CV 3–6%，与正态理论吻合
- 真实站位差距中位数 14%，远大于噪声带

**在复合战术演习里这个结论不成立**，因为：
- 波动不是正态随机，而是**分支（团灭与否、BOSS 阶段）**
- 分支的方差可能极大（一队团灭 vs 全部存活）
- 均值在这种分布上是**很差的统计量**

### 一个你可能没注意的量：Roll5

模拟器自己算了一个 `roll5_mean`（`tactical_exercise.py:1062`）：

> Roll5 期望：每日5次演习取最高分。`E[max of 5] = Σ x_(i)·[(i/N)^5 − ((i−1)/N)^5]`

**这说明游戏的真实目标不是"平均分"，而是"取最高分"（玩家每天打 5 次取最好的）。**

**这是对优化器的重大发现**：如果玩家的实际收益是 `max of 5`，那么：

| 优化目标 | 后果 |
| --- | --- |
| 优化**平均分**（作者做的） | 选出"稳定"的配置 |
| 优化 **max of 5**（玩家真实目标） | 可能选出"高方差但上限极高"的配置 |

**在高方差阵容上，两者会选出不同的赢家。** 而且 `roll5_mean` 的公式只需要**经验分布**，不需要假设正态——模拟器里已经有现成实现。

## 4. 修正后的方案

| 项 | 原说法 | 修正后 |
| --- | --- | --- |
| 粗筛种子数 | 1–2 个 | **战术演习：1–2 个可行**；复合模式：需要更多或改用分支感知统计 |
| 判定统计量 | 均值 ± 2×SE | **战术演习**：够用；**复合模式**：均值不可靠，应看分位数/分支概率 |
| 优化目标 | 期望分 | **应确认是"平均分"还是"Roll5"**——玩家真实目标是后者 |
| 2 倍上下限 | 我认为不可能 | **复合模式下可能**；我没测复合模式 |

### 新的待验证项（按重要性）

1. **优化目标到底是什么？** 平均分还是 Roll5？**这是产品决策，会改变整个算法。** 若是 Roll5，方差大反而可能是优点。
2. **复合战术演习的方差有多大？** 需要实测（我这次只测了战术演习）。
3. **在复合模式下，1–2 种子粗筛的判定一致率是多少？** 若远低于战术演习的 90%，则粗筛必须按模式区分。

## 5. 我的错误与修正

**我应该在报告里明确"这些结论只适用于战术演习"**，而不是笼统地说"1 种子足够"。你举的 2 倍例子正是指出了这个范围问题——**我实测的 CV 只有 3–6%，而你看到的是完全不同的量级，这个矛盾本身就是信号，我一开始没去追。**

追下去之后找到了原因（复合模式的逐队战斗 + 团灭分支），这比原来的结论更有价值。
