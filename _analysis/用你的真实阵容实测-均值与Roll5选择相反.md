## 2. 均值排序在两个方差点上完全失效

用你的真实分数分布做重采样对比（LOW = 同均值、方差缩小；HIGH = 你的真实分布）：

| 方差比 | 正确答案 | 按**均值**选命中率 | 按 **Roll5** 选命中率 |
| --- | --- | ---: | ---: |
| HIGH 方差 1/0.3 | HIGH | **50~52%** | 70% → 83% → **93%** |
| HIGH 方差 1/0.5 | HIGH | **49~52%** | 63% → 74% → **86%** |
| HIGH 方差 1/0.7 | HIGH | **49~52%** | 57% → 65% → **72%** |

**关键观察**：因为 LOW 与 HIGH 的**均值相同**，均值估计器**无论加多少种子都只有 ~50% 命中率——纯掷硬币。**

而 Roll5 估计器在 n=8~32 时达到 **72~93%**，n=64 时 **95~100%**。

**这与上一轮（均值有差异时）的结论互补**：
- 均值有差异时：均值排序会**稳定地选错**（n=128 时 7% 命中）
- 均值相同时：均值排序**完全无信息**（50%）

**两种情况都说明：均值不是决策变量。**

**这张表直接回答了你最初的质疑：**

> **1 个种子能把均值估准到 0.00%，但 Roll5 会低估 12.12%。**

**原因**：均值是中心量，1 个样本就是无偏估计；Roll5 是**极值量**，需要样本覆盖上尾才能估出来。

**所以你的质疑完全正确**：单种子无法体现真实水平——**不是"不够精确"，而是它衡量的量与目标无关**。

**修正后的种子需求**：
- 要 Roll5 误差 < 2%：需要 **8 个种子**
- 要 < 1%：需要 **16 个种子**
- 要 < 0.5%：需要 **32 个种子**

## 4. 修正方案（基于你的真实数据验证）

### 4.1 目标函数（一行）

```python
C5 = 1.162964                       # E[max of 5]，已在你阵容上验证（误差 0.16%）
score = mean(samples) + C5 * stdev(samples)
```

**或**直接用模拟器已有的经验公式（更稳健，不依赖正态假设）：
```python
roll5 = Σ x_(i) · [(i/N)^5 − ((i−1)/N)^5]     # tactical_exercise.py:1062
```

### 4.2 每候选必须记录的两个量

| 统计量 | 用途 |
| --- | --- |
| 均值 | 基线对比、诊断 |
| **标准差** | **计算 Roll5——作者目前完全不记录这个** |

**这是作者算法最小、最关键的缺口**：他花 256 个种子精确估计均值，**却没有记录标准差**——而 Roll5 只需要再记一个数就能算出来。

### 4.3 必须删除的机制

| 机制 | 位置 | 为什么必须删 |

| `3×SE` 波动惩罚 | `quick_review.py:38` | 在 Roll5 下**系统性淘汰高方差 = 最优候选** |
| "波动/临界保护"保留 | `quick_review.retain` | 保护的是低方差平庸候选 |
| 按均值排序 | 全流程 | 实测 50%~7% 命中率 |

### 4.4 采样策略

| 项 | 作者 | 修正 |
