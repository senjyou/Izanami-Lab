## 3. 一个必须注意的实现细节：`小花` 为什么标 CHECK

`小花` 偏度 −0.537（左偏），峰度 +0.352。虽然闭式误差仍只有 0.34%，但**左偏意味着上尾比正态更短**——`E[max of 5]` 会比正态近似**略低**。

**这不影响排序（相对比较仍然有效），但影响绝对值的准确性。**

**建议**：报告值用**经验公式**（`Σ x_(i)·[(i/N)^5 − ((i−1)/N)^5]`），排序用**闭式**。这与"双目标设计"里的建议一致：

| 用途 | 公式 | 理由 |
| --- | --- | --- |
| **搜索排序** | `mean + C5 × sd / c4(n)` | 只需两个矩，小样本稳定 |
| **最终报告** | 经验公式 | 不假设分布形状 |

## 4. 双目标设计的最终参数

| 参数 | 值 | 依据 |
| --- | --- | --- |
| 排序键（均值模式） | `mean` | — |
| 排序键（Roll5 模式） | `mean + 1.162964 × sd / c4(n)` | 全 10 阵容误差 ≤0.36% |
| `C5` | **1.162964** | 数值积分 + 蒙特卡洛双重验证 |
| `c4(n)` | `sqrt(2/(n-1))·exp(lgamma(n/2)−lgamma((n-1)/2))` | 蒙特卡洛验证（n=2~32 吻合） |
| **Roll5 默认种子** | **8** | 你的决定；误差 1~4.4% |
| 高方差候选 | 自动提到 16~32 | 火沙耶需 16~32 才到 <2% |
| 波动惩罚 | Roll5 模式下**关闭** | 实测命中率降至 14~42% |

## 6. 这一系列分析的收敛点

经过多轮验证，现在**可以确定的设计**是：

```python
# 目标模式（用户选择）
objective ∈ {MEAN, ROLL5}          # 默认 MEAN（向后兼容）；ROLL5 默认 8 种子

# 每候选记录（作者缺 sd，必须新增）
mean, sd, n

# 排序键
def rank_key(mean, sd, n, objective):
    if objective == MEAN:
        return mean
    return mean + 1.162964 * sd / c4(n)      # c4 修正小样本偏差

# 报告值（n 足够时）
roll5_report = empirical_roll5(samples)      # 不假设分布形状

# 采样
min_seeds = 8 if objective == ROLL5 else 2   # ROLL5 更严格
high_variance_boost = 16..32                 # 当实测 CV > 8%
```

**与原算法的差异**：
| | 作者 | 修正 |
| --- | --- | --- |
| 记录 | 仅均值 | **均值 + 标准差** |
| 排序 | 均值 | **按用户选择** |
| 波动惩罚 | 始终启用 | **Roll5 下关闭** |
| 种子 | 2/4/8 | **8 起（Roll5）** |
| 高方差候选 | 边缘化 | **重点保留** |
